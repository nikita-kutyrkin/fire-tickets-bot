# 🔥 Fire Tickets Bot

Telegram-бот, который ищет горящие авиабилеты (сильно дешёвые, на сегодня и завтра) и присылает уведомления.

## Как бот понимает, что билет горящий

1. Для каждого маршрута бот считает **обычную цену**: медиану самых дешёвых билетов по дням на 30 дней вперёд. Значение кешируется на сутки.
2. Билет **горящий**, если он дешевле обычной цены на `MIN_DISCOUNT_PERCENT` процентов и больше (по умолчанию 40%) и не дороже `MAX_PRICE` (если он задан).
3. Если по маршруту мало данных и обычную цену посчитать нельзя, присылаются все билеты дешевле `MAX_PRICE`.

Данные о ценах берутся из [Travelpayouts Data API](https://support.travelpayouts.com/hc/ru/articles/203956163) (кэш поисков Aviasales за последние ~48 часов).

## Как получить токен Travelpayouts

1. Зарегистрируйтесь на https://www.travelpayouts.com/ (бесплатно). Регистрироваться можно как физлицо.
2. В личном кабинете откройте **Программы** → найдите **Aviasales** → нажмите **Подключить**. При подключении попросят указать площадку (сайт или Telegram-канал/бот): укажите ссылку на вашего бота, например `https://t.me/fire_tickets_bot`.
3. Откройте **Профиль** (иконка справа вверху) → вкладка **API-токен** (или раздел «Инструменты → API»).
4. Там будут:
   - **API-токен** — строка из 32 символов → в `.env` в `TRAVELPAYOUTS_TOKEN`;
   - **Маркер партнёра** (число, например `123456`) → в `.env` в `TRAVELPAYOUTS_MARKER`. Он добавляется к ссылкам, и с покупок по ним вам начисляется комиссия.

## Деплой на bothost.ru

Бот запускается файлом `main.py` в корне — bothost находит его автоматически. Платформа собирает Docker-образ с Python 3.11, ставит зависимости из `requirements.txt` и задаёт `DATA_DIR=/app/data`: там лежат база и кэш справочников, эта папка переживает обновления кода.

1. Код должен лежать в репозитории на GitHub. Файлы `.env` и `data/` в репозиторий не попадают (см. `.gitignore`).
2. На https://bothost.ru/create-bot.php: платформа **Telegram**, библиотека **aiogram**, токен бота, ссылка на репозиторий, ветка `main`. Главный файл можно не указывать (или `main.py`).
3. В **«Переменные окружения»** бота добавьте `TRAVELPAYOUTS_TOKEN` (и по желанию `TRAVELPAYOUTS_MARKER`, `ORIGIN`, `MIN_DISCOUNT_PERCENT`, `MAX_PRICE`, `DAYS_AHEAD`, `CHECK_INTERVAL_MINUTES`, `TIMEZONE`). `BOT_TOKEN` платформа задаёт сама из токена, указанного при создании.
   Если переменные окружения недоступны на тарифе, загрузите файл `.env` в папку `data` через файловый менеджер панели — бот прочитает его оттуда.
4. В **«Логах работы»** должны появиться строки `База данных: /app/data/bot.db` и `Start polling`.

⚠️ Один токен — один запущенный бот. Если бот работает и на компьютере, и на сервере, Telegram выдаёт ошибку `Conflict`. Остановите локальную копию.

Обновление: `git push` в ветку `main` (на платных тарифах бот обновится сам) или кнопка **«Обновить из Git»** в панели.

## Команды бота

- `/start` — подписаться на уведомления и посмотреть настройки
- `/settings` — настройки кнопками: откуда, куда, скидка, потолок цены, даты
- `/from Москва` — добавить город вылета (можно несколько через запятую)
- `/to Волгоград` — следить только за нужными направлениями (можно несколько через запятую). Без городов — все направления.
- `/check` — найти горящие билеты прямо сейчас. Если горящих нет, а направления выбраны, покажет самые дешёвые билеты по ним.
- `/stop` — отписаться (настройки сохраняются)

У каждого пользователя свои настройки. Бот опрашивает API так, чтобы покрыть всех пользователей сразу, без повторных запросов по одному маршруту.

## Настройки (`.env`)

| Переменная | Что значит |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `TRAVELPAYOUTS_TOKEN` | токен API Travelpayouts |
| `TRAVELPAYOUTS_MARKER` | партнёрский маркер (необязательно) |
| `CHECK_INTERVAL_MINUTES` | как часто проверять цены |
| `TIMEZONE` | часовой пояс для «сегодня» и «завтра» (по умолчанию `Europe/Moscow`) |

Значения по умолчанию для **новых** пользователей (дальше каждый меняет свои в `/settings`):

| Переменная | Что значит |
|---|---|
| `ORIGIN` | IATA-код города вылета: `LED` — СПб, `MOW` — Москва, `KZN` — Казань, `SVX` — Екатеринбург |
| `MIN_DISCOUNT_PERCENT` | минимальная скидка от обычной цены маршрута, % |
| `MAX_PRICE` | потолок цены, ₽ (`0` — без потолка) |
| `DAYS_AHEAD` | `0` — только сегодня, `1` — сегодня и завтра и т.д. |

## Структура

```
main.py             — точка входа
bot/
  main.py           — сборка и запуск бота
  handlers.py       — команды и меню настроек
  checker.py        — периодическая проверка цен и рассылка
  travelpayouts.py  — клиент API Travelpayouts
  db.py             — SQLite: подписчики, настройки, города, отправленные билеты, обычные цены
  config.py         — чтение .env
data/               — база и кэш справочников (создаётся автоматически)
```
